# Karolina Kozak's portfolio

Live at https://karokoz.github.io

- `index.html`: the whole site. Categories, projects, repertoire and photos are lists in the script near the bottom; the comments there show how to add evidence.
- `headshot.jpg`: the portrait.
- `images/`: pictures used on the site (evidence previews, charts, photographs).
- `files/`: PDFs linked from the site (poster, thesis, pitch deck, specifications).

To change something: open the file on GitHub, click the pencil icon, edit, then "Commit changes". The site updates in a minute or two.
